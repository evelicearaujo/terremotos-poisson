# Terremotos pelo mundo: a contagem diária segue uma distribuição de Poisson?

Trabalho Prático — Variáveis Aleatórias e Inferência Estatística
Probabilidade e Estatística (Prof. Pedro Feijó) — UFC Itapajé

Analisa o número de terremotos de magnitude ≥ 5 por dia no mundo (2024 e 2025), com dados do USGS:
análise descritiva, ajuste da distribuição de Poisson (qui-quadrado), intervalo de confiança e teste de hipótese.

## Como executar
```bash
pip install pandas scipy matplotlib
python analise_terremotos.py
```
O script baixa os dados do USGS, imprime as tabelas e salva 3 gráficos (.png) na mesma pasta.
